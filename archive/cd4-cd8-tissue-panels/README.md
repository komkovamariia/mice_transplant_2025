# cd4/cd8 devision with 18*3 trainings

Splenic-main revision with 18 tissue, chain and cell-subset configurations for each of the three ridge models.

- `IJMS_Manuscript_Splenic_Models.pdf` and `IJMS_Source_Splenic_Models.zip` contain the manuscript and its LaTeX sources.
- `TCR_Splenic_Analysis_Results.zip` contains the model coefficients, predictions and validation summaries.
- `Supplementary_Table_S2_Splenic_QC.csv` records the library-level quality-control summary.

The analysis code is in the parent commit. The results archive contains provenance and the model and penalty definitions.

# Figures

This is the only figure root in the repository. Every analytical plot is saved as a
300-dpi PNG and an editable PDF.

Generated files follow this layout:

```text
figures/
├── 01_set_count/<stratum>/
├── 02_sequence_embedding/<stratum>/
├── 03_clone_alloreactivity/<stratum>/
└── 04_cross_approach/<stratum>/
```

Cross-stratum figures are stored directly inside the corresponding numbered method
directory. `results/figure_inventory.csv` lists every generated PNG and PDF path.

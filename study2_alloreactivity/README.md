# Исследование 2 — Поиск аллореактивных клонов TCR α-цепи средствами mirpy

Второй, независимый анализ того же набора данных секвенирования репертуаров
α-цепей TCR (модель MHC-несовместимой трансплантации костного мозга у мышей),
целиком построенный на инструментарии [mirpy / repseq](https://github.com/antigenomics/mirpy).
В отличие от предыдущего исследования (`../venn_original.ipynb`, `../mirpy_analysis.ipynb`),
которое ранжировало V-сегменты по плотности обогащённых aaVJ-комбинаций,
здесь реализован многосигнальный конвейер поиска **аллореактивных клонотипов**
на уровне отдельных клонов.

## Группы

| Группа | Описание |
|--------|----------|
| **g1** | интактный реципиент (контроль) |
| **g5** | аллогенный костный мозг (allo-BM) |
| **g6** | аллогенный костный мозг + котрансплантация донорского тимуса |

## Содержимое

- **`alloreactivity_study.ipynb`** — основной воспроизводимый ноутбук исследования.
- **`статья_2_аллореактивность.docx`** — рукопись статьи (введение с лит.обзором,
  материалы и методы, результаты, обсуждение, 37 источников).
- **`study2_results_tables.xlsx`** — агрегированные таблицы результатов всех методов.
- **`figures_study2/`** — рисунки публикационного качества.

## Аналитические слои

1. **Валидация Исследования 1.** Плотность обогащённых aaVJ-комбинаций
   воспроизведена средствами `repseq`; ранжирование V-сегментов совпало
   с опубликованным (ρ Спирмена = 1,00). Добавление J-сегмента практически
   не меняет выводы (99,9 % клонов не расщепляются).
2. **Профили разнообразия (числа Хилла).** Группа g6 имеет наиболее
   равномерный, наименее клонально-доминированный репертуар
   (клональность: g6 vs g1 p = 0,007).
3. **Биофизическая сигнатура CDR3** (факторы Kidera): 35/46 свойств
   значимо различают алло- и интактные репертуары (Краскела-Уоллиса p < 0,05).
4. **Сеть сходства CDR3 и конвергентные кластеры.** 29/840 кластеров
   значимо обогащены аллогенными группами (FDR < 0,05).
5. **Вероятность генерации (OLGA, mouse TRA).** Алло-конвергентные кластеры
   публичны и имеют высокую Pgen (MWU p < 1e-300).
6. **Публичные клоны и структура компартментов.** Прослеживание
   донор→периферия у g6 (в среднем 18,8 % клонов).
7. **Интеграция сигналов** в единый ранжированный список кандидатов;
   верхушку занимают конвергентные мотивы **NSNNRIF/TRAJ31** и **SSGSWQLI**,
   собираемые через множество разных V-сегментов, присутствующие у всех
   аллогенных мышей и отсутствующие у интактных.
8. **Аннотация VDJdb (mouse TRA).** Кандидаты дают 8,4-кратное обогащение
   по точным совпадениям над интактным нулём (перемешанный нуль = 0 %).
